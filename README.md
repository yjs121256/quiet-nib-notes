# Quiet Nib Notes

Independent, research-based guides to cartridge and converter fountain-pen care and troubleshooting.

This repository holds the static site intended for GitHub Pages at https://yjs121256.github.io/quiet-nib-notes/

**Pages is not live yet.** The `Deploy GitHub Pages` workflow is in `.github/workflows/pages.yml` (with `actions/configure-pages` `enablement: true`). Runs fail at "Configure Pages" because creating a Pages site is not allowed for the Actions `GITHUB_TOKEN` (`Resource not accessible by integration`, [run 8](https://github.com/yjs121256/quiet-nib-notes/actions/runs/44995270086)). The GitHub API connector used to publish this repo has no Pages-enable tool.

To go live (one repo-settings step, no purchase):

1. Open https://github.com/yjs121256/quiet-nib-notes/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions** and save
3. Re-run the latest "Deploy GitHub Pages" workflow (Actions tab), or push another commit to `main`

After that, the expected URLs are:

- Site: https://yjs121256.github.io/quiet-nib-notes/
- About: https://yjs121256.github.io/quiet-nib-notes/about/
- Affiliate disclosure: https://yjs121256.github.io/quiet-nib-notes/affiliate-disclosure/
- Site privacy: https://yjs121256.github.io/quiet-nib-notes/privacy/
- Newsletter archive: https://yjs121256.github.io/quiet-nib-notes/newsletter/
- Product Evidence Lens privacy: https://yjs121256.github.io/quiet-nib-notes/product-evidence-lens/privacy.html

The About page states plainly that this is not a manufacturer, retailer, or repair workshop, and that no formal repair credentials are claimed. The affiliate-disclosure page states that no affiliate programmes are enrolled as of 22 November 2026. Articles keep their original citations.
