Catalog Sentry Local

A local checklist for product CSV files. The free command-line tool is $0. A Pro plan is proposed at $19 / month; that tier is not built yet, and no paid checkout is live.

Catalog Sentry Local is a local, deterministic preflight auditor for product CSV files. You run it on your own computer before importing a catalog into a store, marketplace, or feed tool. It flags broken rows, lost leading zeros, scientific-notation GTINs, invalid prices, duplicate SKUs, non-absolute URLs, and cells that a spreadsheet could execute as formulas (CSV injection).

It is written and published by 윤주컴퍼니 (Yunju Company), Gwangju, Korea. Contact: yjs121256@gmail.com.

This page describes the product honestly. There are no customers, reviews, or case studies to show, and none are invented here.

What it does

  • Python 3.9+ standard library only. No runtime dependencies, no network calls, and no telemetry. URLs in a CSV are checked for syntax only and are never fetched.
  • It uses a generic schema (sku, title, price, currency, availability, product_url, image_url, plus optional fields). It is not an official Shopify, Google, Amazon, or OpenAI import validator, and it does not certify that an import will succeed.
  • It writes reports as Markdown, HTML, JSON, or CSV. Input files are never modified.

A fuller technical description, including the check list and limits, is in the project’s local documentation. The public pages you need before buying a paid plan are this page, the terms, the refund policy, and the privacy policy.
